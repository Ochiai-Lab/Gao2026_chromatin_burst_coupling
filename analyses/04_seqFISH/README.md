# 04_seqFISH

seqFISH reanalysis used in Fig. 2.

- The final allele key is the combination of FOV, cell, and allele identifier.
- An earlier public candidate used a different uniqueness rule and counted
  7,866 Active alleles; the final analysis counts 7,612.
- The primary public notebook has been replaced by the exact final plotting
  notebook, with only configurable input/output paths added.
- Re-execution generated three output tables that are byte-identical to the
  deposited Source Data tables.
