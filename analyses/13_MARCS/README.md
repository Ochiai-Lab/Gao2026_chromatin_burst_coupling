# 13_MARCS

Reanalysis of the published MARCS protein- and complex-level response tables used for Supplementary Fig. 7.

- Public notebook: `notebooks/MARCS_HDAC_reanalysis_notebook.ipynb`
- Deposited final tables and source workbooks: `13_MARCS/` (the earlier
  `revision/13_MARCS/` layout is also accepted).
- Full recomputation uses the deposited MARCS protein and complex XLSX
  workbooks without changing the statistical logic.
- The deposited CSV files contain the protein-level effects and all complex-wise effects and adjusted P values plotted in Supplementary Fig. 7.
- The audited notebook completed all cells and generated 27 figures. The
  deposited 129/130/130 complex-wise rows matched the plotted analyses.
- Notebook outputs and generated figures are excluded from the GitHub package.
