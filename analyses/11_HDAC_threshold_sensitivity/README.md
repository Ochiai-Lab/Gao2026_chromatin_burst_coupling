# 11_HDAC_threshold_sensitivity

Sensitivity analysis for the mTetR and MCP intensity thresholds used in the
HDAC-inhibitor time-lapse analysis.

- The deposited sweep contains 120 validated threshold-condition summaries.
- `scripts/replot_threshold_sensitivity_from_tables.py` regenerates the final
  compact sensitivity figure from those values.
- The regenerated PDF differs from the final source only by a one-pixel crop;
  all plotted numeric values are unchanged.
